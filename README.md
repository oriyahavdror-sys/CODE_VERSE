## 📖 תיאור

**CODE VERSE** הוא משחק למידה אינטראקטיבי שמלמד אבטחת סייבר בצורה כיפית ונגישה לכולם. המשחק תומך בשלוש שפות (עברית, אנגלית, ערבית) ומתאים למתחילים מוחלטים ועד מתקדמים.

למד על:
- 🌐 אבטחת אתרים
- 🔐 הצפנה וקריפטוגרפיה
- ⚔️ בדיקות חדירה ואבטחה
- 💻 קוד בטוח
- 🛡️ הגנה על מידע

## 🚀 התחלה מהירה

### דרישות מקדימות

```bash
Node.js 16+ 
npm או yarn
```

### התקנה

```bash
# שכפל את המאגר
git clone https://github.com/yourusername/code-verse.git

# נווט לתיקיית הפרויקט
cd code-verse

# התקן תלויות
npm install

# הפעל שרת פיתוח
npm start
```

### או השתמש עם Claude Artifacts

פשוט העתק את הקובץ `src/CodeVerse.jsx` ל-Claude Artifacts והרץ אותו ישירות!

## 🎮 איך לשחק

### 1️⃣ בחר שפה
בחר את השפה המועדפת עליך: עברית, אנגלית או ערבית

### 2️⃣ צור חשבון
- הירשם עם שם משתמש וסיסמה
- הגדר שאלת אבטחה לשחזור סיסמה
- ההתקדמות שלך נשמרת אוטומטית!

### 3️⃣ השלם את המדריך
למד את היסודות של אבטחת סייבר דרך שקופיות אינטראקטיביות

### 4️⃣ בחר את המסלול שלך
בחר התמחות:
- אבטחת Web 🌐
- קריפטוגרפיה 🔐
- בדיקות אבטחה ⚔️

### 5️⃣ בחר רמת קושי
- 🌱 מתחיל - מושלם למי שמתחיל מאפס
- ⚡ בינוני - למי שיש לו ידע בסיסי
- 🔥 מתקדם - למשתמשים מנוסים

### 6️⃣ השלם משימות
- קרא את מדריך המשימה
- כתוב קוד כדי לפתור אתגרים
- קבל רמזים אם אתה תקוע
- השתמש ב"לא יודע" כדי לקבל הסברים
- הרווח XP ומטבעות!

### 7️⃣ קנה והתאם אישית
- קנה אווטארים חדשים
- פתח ערכות נושא
- קבל power-ups
