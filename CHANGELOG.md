# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-11

### Added
- 🎮 Initial release of CODE VERSE
- 🌍 Multi-language support (Hebrew, English, Arabic)
- 📱 Fully responsive design for all devices
- 🔐 User authentication with password recovery
- 🎓 Three learning paths: Web Security, Cryptography, Security Testing
- 🎯 Mission system with multiple difficulty levels
- 💾 Auto-save functionality
- 🏆 Leaderboard system
- 🛒 Shop with themes and avatars
- 💡 Hint system and "I don't know" learning flow
- 🎨 8 different theme options
- 👥 6+ unique avatars
- 📊 Personal statistics tracking
- 🌱 Beginner-friendly tutorial system

### Features
- Complete cybersecurity curriculum
- Interactive code challenges
- Practice mode for reinforcement
- XP and coins reward system
- Boss battles
- Daily missions
- RTL support for Hebrew and Arabic
- Touch-friendly interface
- Works in Claude Artifacts
